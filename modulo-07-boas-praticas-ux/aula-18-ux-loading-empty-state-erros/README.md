# Aula 18 – UX, Loadings e Tratativas: O Tapete Vermelho 🎩

[Voltar ao curso](../../README.md) | [Calendário](../../docs/calendario-aulas.md) | [Tutoriais](../../TUTORIAIS.md)

---

Bem-vindo à Aula 18! Nesta aula você vai aprender a tratar o usuário com carinho quando o app está pensando, vazio ou com erro. Um app que funciona é bom. Um app que **protege o usuário do medo de travamento** é Premium.

> [!IMPORTANT]
> **Meta da aula:** terminar sabendo exibir um spinner enquanto os dados carregam, uma mensagem amigável quando a lista está vazia, e um alerta de erro quando algo dá errado. Se o seu app não "explode" diante de problemas, a missão está cumprida. 🎯
