# 🧪 Projeto Expo – Módulo 07 (UX e Projeto Final)

Este é um **projeto Expo real e incompleto** de propósito, focado nas áreas deste
módulo. Cada tela tem uma ou mais **TAREFAS** marcadas com `// TAREFA (Aula NN):` —
complete-as conforme você avança nas aulas.

## 🚀 Como começar

1. **Node.js** (LTS) instalado e o app **Expo Go** no celular.
2. Nesta pasta, rode:

```bash
npm install
npm start
```

3. Escaneie o QR Code com o **Expo Go** (mesma rede Wi-Fi).
4. Abra cada tela e complete as **TAREFAS** (`// TAREFA (Aula NN):`) do código.

> Se aparecer erro de rede no Expo Go, use o modo túnel: `npm start -- --tunnel`.

## 🗺️ Telas e tarefas deste módulo

Áreas cobertas: **Aula 18 (loading, empty state e erros), Aula 19 (boas práticas) e Aula 20 (projeto final).

- `app/index.tsx` — tela inicial do projeto final (Aulas 18 e 20).
- `app/_layout.tsx` — pilha de telas do projeto final.

## 📦 O que já vem instalado

O `package.json` inclui (versões compatíveis com o **Expo SDK 54**): `expo`,
`expo-router`, `expo-status-bar`, `expo-image-picker`, `expo-location`,
`expo-notifications`, `@react-native-async-storage/async-storage` e `expo-sqlite`.
Basta `npm install` — os pacotes já estão prontos para você desbloquear cada área.
