# Aula 15 – A Fúria do CRUD Completo (Integração Lógica)

[Voltar ao curso](../../README.md) | [Calendário](../../docs/calendario-aulas.md) | [Tutoriais](../../TUTORIAIS.md)

---

Na aula passada, criamos a tabela e inserimos dados. Mas um banco de dados que só **recebe** informações é como uma caixa de correio sem carteiro. Hoje vamos aprender a **ler**, **atualizar** e **apagar** registros — completando o ciclo completo chamado **CRUD**.

> [!IMPORTANT]
> **Meta da aula:** sua lista na tela deve refletir exatamente o que está no banco. Adicionar, apagar e editar um item deve atualizar a tela instantaneamente. 🎯
