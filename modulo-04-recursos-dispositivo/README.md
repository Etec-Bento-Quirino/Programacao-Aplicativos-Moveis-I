## Projeto Expo do módulo

Este módulo tem um **projeto Expo** próprio na pasta [`app/`](app/README.md) com telas
incompletas marcadas com `// TAREFA (Aula NN):`. Conforme você avança nas aulas,
complete as telas correspondentes:

```bash
cd app
npm install
npm start
```

Use o app **Expo Go** no celular para escanear o QR Code e ver o app.
