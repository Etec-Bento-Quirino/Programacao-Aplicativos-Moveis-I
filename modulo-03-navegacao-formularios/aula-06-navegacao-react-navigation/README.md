## O Desafio Prático

Pense no WhatsApp: ele tem a lista de chats, a tela de status e a tela de configurações. São várias telas, mas o app não "recarrega" quando você troca de uma para outra. Ele faz isso de forma fluida, como se você estivesse andando entre cômodos da mesma casa.

Nesta aula, você vai aprender a construir essa "casa" com várias telas. Vamos usar o **Expo Router**, que cria rotas automaticamente a partir dos nomes dos arquivos — sem configuração chata e manual.

> [!IMPORTANT]
> **Rota** é o caminho que o app segue para chegar em uma tela. Assim como seu celular tem "atalhos" na tela inicial, o Expo Router cria atalhos internos para cada tela do app.
