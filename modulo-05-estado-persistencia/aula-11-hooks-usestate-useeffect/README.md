# Aula 11 – O Cérebro do App: useState e useEffect (Hooks)

[Voltar ao curso](../../README.md) | [Calendário](../../docs/calendario-aulas.md) | [Tutoriais](../../TUTORIAIS.md)

---

Até agora seus apps tinham esqueleto (Views) e pele (StyleSheet), mas **nenhum cérebro**. O botão era clicado e… nada acontecia. Nesta aula você instala o "cérebro" dos seus componentes: os **Hooks** — ferramentas que guardam memória e fazem a tela se redesenhar sozinha.

> [!IMPORTANT]
> **Meta da aula:** criar um app que reage ao toque do usuário — botão clicado, tela atualiza. Se você conseguir ver o contador subir de 0 para 1, a missão está cumprida.
